### Fixed

- **A debate revision keeps every claim it does not write again.** A claim in force is replaced only by one block of the revision that restates it, and, where the revision is placed by what it states, only while every address the claim names is stated by some block of the revision (in hex or in a decompiler's name; a whole address and its offset under an image base count as one); a claim's values spread over several of the revision's claims no longer count as a restatement. A claim whose subject the revision states nowhere stays in force whole, marked carried forward, and its values are no longer recorded as dropped. A correction that names the claim's addresses still replaces it; one that changes or leaves out an address stands beside it, and the claim's note and the run summary name the revision claim that states it again and the addresses it leaves out. A block under a claim's number that restates it replaces it, and a blocking line that named a claim still withdraws it by rule. `WITHDRAW CLAIM` lines work as before.
- **A quoted value written in digits that are no decimal number is read as written.** A superscript or circled digit in a claim is compared as the quoted value it is, in the revision merge and in the record of values a revision no longer states.

### Added

- **`scripts/replay/remerge_revisions.py` merges a stored run's revisions again**, under the current rule and under one that pools a claim's values over blocks, from the answers in force its log holds, and prints per analyst and round the claims each rule restated, carried (and carried beside a restatement), withdrew and left with dropped values, and each claim the current rule keeps in force. It reads the stored run only and calls no model.
