### Changed

- **The agreement question names the call that redid a failed call (T-600).** Its facts on a failed call and the later call that answered for the same address name, for a call a later call redid, the call the run summary names as the redo (the same question asked again), never an earlier call that only read a few instructions from the address. The run summary, the limitations facts and the agreement question read one redo map.
- **A denial of a name the run holds is read against the ledger (T-600).** A sentence of any passage the agreement question may rewrite, the conclusion and the limitations included, that denies something of an API, an export or a decoded text the run's answers hold is held, and the question is shown what the ledger holds of that name: the routines the function index lists calling the API and through which slot, with the call lines of each listed routine and every slot they write named; the export's names, address, callees and their callees, and its listing; the routines a decoded text is tied to. A sentence naming no such name that opens by pointing back ("These names are …") is read on the APIs of the sentence before it. A denial set in what a run saw is not read this way. Where a negated clause says nothing but the relation the ledger records ("no routine calls X", "X is not called", "no 'x' text appears in the decoded strings") and the ledger states it, a keep is refused and a rewrite must state the fact citing every entry it cites; a body sentence left standing gets the fact's clause, and a closing sentence is left out, recorded as `agreement.ledger_contradicts`. Any other such sentence is the model's to answer, with the fact shown, and a closing keep on no source is refused while that fact speaks of it. The facts of names fill at most 24,000 characters per question; the rest are counted.
- **A limitations sentence denying something of a redone call is held to the failed calls (T-600).** A sentence whose negated clause names a failed call by its tool or kind, naming an address it was asked for ("the decompiler produced no function at 0x2200") and citing no call that redid it, is held as one saying the call failed is, and a keep of it is refused while a later call redid the call.
