### Changed

- **The agreement question names the call that redid a failed call (T-600).** Its facts on a failed call and the later call that answered for the same address name, for a call a later call redid, the call the run summary names as the redo (the same question asked again). The run summary, the limitations facts and the agreement question read one redo map.
- **A denial of a name the run holds is read against the ledger (T-600).** A sentence of any passage the agreement question may rewrite, the conclusion and the limitations included, that denies something of an API, an export or a decoded or plain text the run's answers hold is held, and the question is shown what the ledger holds of that name: the routines the function index lists calling the API and through which slot, with the call lines of each listed routine and every slot they write named; the export's names, address, callees and their callees, and its listing; the routines a decoded or plain text is tied to. An API or an export spelled like a word of prose counts only written as code or beside a word saying it is a function; an export or an import counts only from an answer about the sample itself. A sentence naming no such name that opens by pointing back ("These names are …") and denies a relation an API is held under is read on the APIs of the sentence before it. A denial set in what a run saw is not read this way. Where every word of the whole sentence, in all its clauses, is accounted for ("no routine calls X", "X is not called", "'x' was not decoded") and the ledger holds the name under the relation it denies (a text under the decoded or the plain strings, as the function index lists it), a keep is refused and a rewrite must state the fact citing every entry it cites; a body sentence left standing gets the fact's clause, and a closing sentence is left out, recorded as `agreement.ledger_contradicts`. A word is accounted for only as the one name decided, a word form of one relation it is held under ("call", "calls", "called", "calling"; never "callee", "caller" or "callback") or a word every such relation is held in ("string", "text"), exactly one negation, an article, a form of "be", "do" or "have", "by", "any", "at", "in", "of" or "for", an evidence citation, and, for an API, whose calls are read in the routines a sentence names, an address, a routine noun, a word naming an address, or a list of addresses ("0x1400 and 0x1500"). Any other word, in any clause, leaves the sentence to the model: a second name the run holds, a word saying what a run did ("executed", "reached"), "other", "only", "all", "except", "apart from", "if", a slot, a callee or a caller; so does an address named with a preposition ("outside 0x1400"). A denial of an export or an import is never read as backed where an answer about another file was set aside. A name written as a call ("`connect()`") is read as the name. Any other such sentence is the model's to answer, with the fact shown, and a closing keep on no source is refused while that fact speaks of it. The facts of names fill at most 24,000 characters per question; the rest are counted.
- **A limitations sentence denying something of a redone call is held to the failed calls (T-600).** A sentence naming a failed call by its tool or kind and an address it was asked for, citing no call that redid it, whose every word, in all its clauses, is accounted for by the same rule and the call's own words, with the call's own verb straight before the negation ("the decompiler produced no function at 0x2200", "the decompiler produced no function at 0x2200 or 0x1030", never "the decompile of 0x2200 shows no network call" or "the decompiler produced no other function at 0x2200"), is held as one saying the call failed is, and a keep of it is refused while a later call redid the call. The reason a denial gives is read as a sentence of its own ("the boundaries of 0x2200 and 0x1030 are not confirmed, because the decompiler produced no function at either address"), and a sentence citing the failed call itself and no call that redid it is held whatever else it says.
