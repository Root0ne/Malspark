### Changed

- **The agreement question names the call that redid a failed call (T-600).** Its facts on a failed call and the later call that answered for the same address name, for a call a later call redid, the call the run summary names as the redo (the same question asked again). The run summary, the limitations facts and the agreement question read one redo map.
- **A denial of a name the run holds is read against the ledger (T-600).** A sentence of any passage the agreement question may rewrite, the conclusion and the limitations included, that denies something of an API, an export or a decoded or plain text the run's answers hold is held, and the question is shown what the ledger holds of that name: the routines the function index lists calling the API and through which slot, with the call lines of each listed routine and every slot they write named; the export's names, address, callees and their callees, and its listing; the routines a decoded or plain text is tied to. An API or an export spelled like a word of prose counts only written as code or beside a word saying it is a function; an export or an import counts only from an answer about the sample itself. A negated sentence naming no such name and no address that opens by pointing back ("These names are …", "It is not …") is held on the names of the sentence before it. A denial set in what a run saw is not read this way. A name written as a call ("`connect()`") is read as the name. Code decides none of these sentences from their words: the model keeps or rewrites each one, or leaves a closing one out, with the fact shown, and a closing keep on no source is refused while that fact speaks of it. The facts of names fill at most 24,000 characters per question; the rest are counted.
- **A limitations sentence naming a redone call is held to the failed calls (T-600).** A negated sentence that names a failed call a later call redid by an address the call asked for together with its tool or kind, or cites the failed call, and cites none of the calls that redid it, is held as one saying the call failed is, whatever else it says. The question names, for each such sentence, the calls that redid it, and a keep of it is refused until it cites one of them; the refusal names the entries to cite.
