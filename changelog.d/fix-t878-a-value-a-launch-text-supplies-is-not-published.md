- **A value a further detonation's launch text supplies is not published as the sample's (T-878).** The build records each value a further detonation's launch text supplies — a whole argument, the host of `user@host`, of a URL or of `host:port`, a switch's value written against it (`-oX`, `/D=X`, `/path:X`, `--x=X`), a part a path's separators, quotes or key-value marks delimit, the end after an environment variable of a path a read of that detonation writes, an address the detonation resolved for a host the launch text holds; compared without case and with `/` read as `\` — with each entry that holds it whole outside the reads of the detonations launched with it, outside what an entry's own call asked for and with a call not given their launch text. The publish rule, handed the report at every call, refuses right after the sample's own digests a value on which a further detonation's mark stands, which its launch text supplies and which no such entry holds, on every surface (the IOC table, `/iocs`, STIX, MISP, the drafted rules and the Sigma selections), a judge's value included, saying which launch text holds it and what the run's search left out. A value a row of the job's own detonation holds, a value the file's text, a decoded string or a reverser's read holds, and a value the sample produced under a launch value publish as before.
