### Added

- **A finished run records the tools it ran (T-668).** The run summary's `environment` block gains `tools`: one row per tool server or provider that served the run, saying whether its tools were offered to an agent, called by one or run by a triage pack step, with the name and version the server gave when attached and what each requirement its tools declare was on its host — a library's installed distribution and version, a rule set's file count and one SHA-256 over its files, a program's version where its tool declares how to ask it, else "not reported". The pack steps the worker runs itself have a row of their own. The facts come from the capability manifest every tool server already answers, which now carries them, read once when the server starts; a server with no manifest gives its name and version only.
