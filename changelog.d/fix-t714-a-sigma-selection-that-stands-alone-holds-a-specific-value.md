### Fixed

- **A Sigma selection that can match alone holds a specific value, and a Sigma draft carries only the techniques that name what it selects (T-714).** Each selection of a Sigma draft can match alone, so `detection_signatures.selection_specific` takes out every value the benign-location catalogue calls every Windows host's (`benign_reason`, asked of the value as selected, a sandbox-recorded key or image included) and every `contains` value another selected value of the draft holds as whole path components (the folder a selected file lies in); a selection left empty is taken out, and a draft left with none is not built, its reason printed in the existing "No Sigma draft" line. The builder and `drafts_not_built` read the one decision. A Sigma draft is tagged with a technique only where the technique's evidence quotes or roots name a selected value whole and delimited, with a tactic only for a technique kept, and with no `tags` key when none is. No text a model reads changed; the YARA and Suricata drafts are unchanged.
