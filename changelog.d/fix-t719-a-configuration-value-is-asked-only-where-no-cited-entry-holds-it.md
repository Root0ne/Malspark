### Fixed

- **A configuration value is asked about only where no cited entry holds it (T-719).** A configuration cell of several spans is held where every span of it is held by a cited entry; only list punctuation is no span, a span holding a backslash or a slash runs to the end of its part, a number is held only with the span before it in its part (one first in its part is read alone, and a short one holds nothing), and a cell of one span and an identifier row are read whole. A value with a backslash is also held as a C string writes it, a 32-bit constant also sign-extended to 64 bits, and a registry path's leading hive by its other name or its predefined handle where that stands before the rest of the path on the same line of the entry. The question names the spans no cited entry holds and, for a path, the whole leading part a cited entry holds. A value a cited entry holds only inside a longer run of letters or digits is asked once under `report.value_inside_a_longer_token`, with the run shown and both answers offered; a row kept after it is printed with a mark saying so. A configuration or identifier row whose finding was never asked says so in its mark.
