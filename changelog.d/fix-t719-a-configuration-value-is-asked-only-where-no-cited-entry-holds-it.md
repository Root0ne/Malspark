### Fixed

- **A configuration value is asked about only where no cited entry holds it (T-719).** A configuration cell of several parts is held where some cited entry holds each literal it states; a path is one literal, a name with a number one pair, and an identifier row is read whole. A value with a backslash is also held as a C string writes it, a 32-bit constant also sign-extended to 64 bits, and a registry path's leading hive by its other name or its predefined handle. The question names the literals no cited entry holds and, for a path, what a cited entry holds of it. A value a cited entry holds only inside a longer run of letters or digits is recorded under `report.value_inside_a_longer_token`, never asked, and marked beside its row. A configuration or identifier row whose finding was never asked says so in its mark.
