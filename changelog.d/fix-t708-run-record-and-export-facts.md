### Fixed

- **The stored STIX bundle's envelope holds `type`, `id` and `objects` only (T-708).** STIX 2.1 defines a bundle by those three properties; `spec_version` belongs to each object, where every object keeps it. The stored export and the judge's stored bundle no longer add `spec_version` to the envelope; `x_` properties stay where they were.
- **An answer replaced while claims it began were unread is in the run record (T-708).** Only the answer in force carries its unread-claims reason into the run's degradation reasons, as before. Each answer that leaves force with such a reason, replaced by a validation retry, a later round or a further turn, is a row of `run_summary.validation.claims_unread_replaced`: the analyst, its round, the claims begun, read and unread, why, and what replaced it. The row is no degradation reason and no sentence of the report.
- **A source cited to state an absence is shown apart from a technique's evidence (T-708).** A source every statement naming a technique cites in a clause that denies a record or a match ("[ev_0203] DNS names (no match)", "do not appear") is listed in the technique's `absence_sources`; a source any statement cites for the behaviour stays evidence. Every surface names such sources after the evidence as "cited for an absence: …": the ATT&CK table, the analyst report's note, the ATT&CK defence rows, the MISP and Navigator comments and the STIX edge's evidence note; the API row lists them in `absence_sources`. The judge's evidence summary traces the technique to its other sources and names these apart. The row keeps every source. The clause that writes a citation also reads "no match" and "does not appear" as a denial of what it cites, outside quoted text, only where the cited entry's own stored answer found nothing: its declared rows place holds no row.
