### Fixed

- **A value taken from the file's text is published only when an observation independent of that text confirms it (T-704).** A path, a registry key or a mutex the string sweep read is confirmed by what a sandbox watched, by what a persistence mechanism names, or by an entry an analyst cites whose declared kind watched the sample or recovered the value (a sandbox or capture, a rule over its events, an emulator, a decoder, a hash resolver). A listing, a string search, a decompile, a byte read or an extractor reads the same bytes again and confirms nothing. A tool that declares no kind confirms a value unless the value stands as plain text in the string sweep's record. The decision is per entry: a tool section counts only when every entry it stands on is cited. A path or a registry key the sweep cut out of a longer token carries that token (`cut_from`) and is never published. A name a recovering tool read is asked, in the tool's own spelling, whether it reads as a host, and where the strings listing is partial the "also a plain string" holdout reads the sample's bytes. Every refusal names its reason in the IOC table.
