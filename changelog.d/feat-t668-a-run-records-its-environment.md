### Added

- **A finished run records the environment it ran in (T-668).** The run summary carries an `environment` block, wherever the summary is stored, served and exported: the worker's host (operating system and release, machine type, processor model, and the kernel's logical processors and total memory, with the processors and memory limit the worker process itself may use where its control groups say), and per agent one row for each model it was built to send with — the sampling parameters and thinking switches its provider adapter read off the request body the client would send, the statement that none was sent and the provider's default applied, or the statement that the adapter reported nothing; the effort level with the setting it came from, or why none was sent; and how many calls that model answered, so a fallback that was never needed reads 0 — beside each model identifier the provider's answers named, a path-shaped one kept by its base name; the published benchmark evidence keeps those model identifiers as recorded. Each fact appears only where it was read; a summary stored without the block reads as before. Every shipped provider adapter reads its request body this way; a provider without the reading is recorded as not reported, never as sending nothing.

### Fixed

- **The model build log line states the sampling actually sent (T-668).** It used to print the temperature handed to the provider, which a model whose API or client library drops sampling parameters is never sent. The line now names the sampling read off the request body the client would send.
