### Changed

- **A section 5 absence is held unless the clause that states it names an address (T-580).** In section 5, the passage written from the code, a sentence that names an address in one clause and denies something else in another ("the code shown calls file-creation wrappers from 0x33ac, but the copy destination is not established") is held where a clause stating the absence (its parts between clause joins, citations, semicolons and colons) names no address. A clause that points back still names what the sentence names: a word pointing back ("its body is not read", "this is not established") or a clause a relative, a concession or a reason opens ("…, which is not established", "…, though its target is not shown", "because …"). In the passages written from the claims (key findings, identifier rows, procedures, the flow) a sentence naming an address is read whole, since such a clause there is most often about the row's own code or about what a run saw. A sentence naming no address is read whole everywhere, and keeps its whole-code question even when it is also held as calling listed code unread. Each such held sentence is one more row of the existing agreement question; no call is added.
