### Fixed

- **A dropped file is one row with the size its reader states, and an observed request keeps its user agent (T-719).** Every sandbox view is read through one entry point that takes the reader's declaration, so the pack, the read of a later detonation and an agent's call state the same row for one record, and the report lists the file once. Which fields of a dropped row state its size is the reader's declaration (`Reading.dropped_size_fields`): every declared field is read and the first one stated wins, then `size`; a row stating none prints "not recorded", and a stated size of zero prints as zero; a size is a number or text that is a number, and anything else prints "not recorded". A URL a request was observed for carries the method and the user agent of one request record. The report reads the user agent with the job's reader, taken from the job's record, from every field that reader declares states it (`Reading.request_user_agent_fields`), then `user_agent`; a later detonation's request is read by `user_agent`. The network view states each request record as the record states it, the user agent once.
