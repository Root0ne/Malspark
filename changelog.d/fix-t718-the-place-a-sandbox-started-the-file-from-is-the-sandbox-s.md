### Fixed

- **The place a sandbox started the submitted file from is read as the sandbox's (T-718).** A process that runs the submitted file by its submitted name or its digest, whose image is that file, and that no process running the file started, is where the sandbox placed the file. It is read from the report's own processes, each process row read the one way the document reads it (its id, its parent, its name and its image path) whichever reader built it, never from the rows a view prints; where a parent cannot be told, nothing of that task is marked, and a path the system itself ships (or a bare name it ships) is never the place. A path the report shows written during the run (its collected files or its file-write operations) is never marked, nothing is where the report records no file writes (read with no reader, where it shows none), and at most one row of a task is marked: the earliest started, none where the starts cannot be compared. The process view marks its row `staged_by_sandbox: true` and says once that it is the first process that runs the submitted file, started by no process that runs it, at a path the report does not show written, and that the sandbox started the file from there; a copy the sample makes of itself and runs is never marked. The report's process tree carries the mark, and the pack, the evidence table, the process tree and its figure write the same words beside the row.
