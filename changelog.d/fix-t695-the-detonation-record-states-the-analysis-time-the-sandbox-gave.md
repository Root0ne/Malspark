### Fixed

- **A detonation's record states the analysis time the sandbox gave, beside the time asked (T-695).** A hosted sandbox can run a task for less time than the submission asked, with no error, and the run said nothing of it. Each row of `environment.detonations` now carries `analysis_time`: per sandbox task, the analysis time the submission asked and the time the sandbox's own report states it gave (a Triage overview's `timeout` per behavioural task, a CAPE or Cuckoo report's `info.duration`, or where an operator's declared format places it with the new `analysis_seconds_paths`), each `not reported` where nobody stated it. Where a task ran for less time than was asked, the run's limitations say so with both numbers. The time a submission asks is unchanged, and a summary stored without the field reads as before; the block's shape version is now 5.
