### Fixed

- **A detonation's record states the analysis time the sandbox granted, beside the time asked (T-695).** A hosted sandbox can grant a task less analysis time than the submission asked, with no error. Each row of `environment.detonations` carries `analysis_time`: per sandbox task, the analysis time the submission asked and the time the sandbox's own report states it granted (a Triage overview's `timeout` for every behavioural task, or where an operator's declared format places it with the new `granted_seconds_paths`, also served by `GET /api/v1/sandbox-report-formats`), each `not reported` where nobody stated it. The time asked is stated only for a submission the provider posted itself; a CAPE or Cuckoo report states no time granted. Where a task is granted less time than was asked, the run's limitations say so with both numbers. The time a submission asks is unchanged, and a summary stored without the field reads as before; the block's shape version is 5.
