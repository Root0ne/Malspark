A request row of a kind the reader does not read is kept whole in a `task.network.requests.<kind>` channel, counted by its rows. An answer with no request is kept and counted the same way. A request takes the process facts of the flow it rode on, and one rule decides an address, a name and a URL: where the records naming a process name one outside the sample's lineage (another process, the launcher's, one the report does not list, or a disputed one), the value is not published as observed from the sample and the answer says whose it is; where no record names a process, the value is decided as without one. A dropped file's guest path is shown where the reader declares the field holding it.
