### Changed

- **An answer served from an earlier entry may be asked afresh (T-659).** Where the platform answers an identical tool call from the entry of an earlier one with no tool run (a whole-function read the loop already holds, the agent's own call of an earlier chunk, round or loop, or an identical call of the job by any agent), the answer now ends with one platform sentence: asking again with the same arguments runs the call fresh, once. The identical call after it runs the tool and is recorded as a call that ran. It counts as a run, so the identical call after it is refused as before and the refusals still end a stalled loop; each call gets one fresh run per loop. The rule holds for every tool, declared or not. A call no layer serves runs twice before its refusal, as before.
