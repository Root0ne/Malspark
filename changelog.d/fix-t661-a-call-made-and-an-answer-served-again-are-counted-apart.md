### Changed

- **Tool call counts carry the calls made and the answers without a run, by one definition (T-661).** Every count of tool calls reads one rule for whether a ledger entry is a call whose tool ran or an answer given without a run (served again from an earlier entry, or a guard's answer), and carries both: the disclosure block prints "40 calls (+1 answered without a run)" where a row has such answers, and the stored record keeps `served` beside `calls` on each row, in the tool-effects part and in the per-agent tool latency. The calls no row counts, all on this machine (the platform's in-process tools, questions put to the team, calls to a tool server run on this machine), are one new line, so the block's lines count every ledger entry once, as the finished tool-call events do. The record's version is 5; a stored record of an earlier version reads as before.
