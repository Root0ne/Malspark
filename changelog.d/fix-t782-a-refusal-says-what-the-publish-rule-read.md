### Fixed

- **A refusal in the indicator table says what the publish rule read and what the reading gave.** Every network
  row's refusal has the publish rule as its subject. A sandbox address's refusal says what the rule read in the flow
  rows to it: which processes made them, whether they stand inside the sample's process tree, and how much of the
  capture was read. A host, URL or mailbox the host test refuses carries that test's own reason. A value held only
  by the string sweep is refused with the row it is from and what the rule's lookup found. A publish answer is
  written once, as its parts, and every surface composes its sentence from them, so the report, the indicator list,
  the evidence bundle, the job package, the judge's question and a served stored report agree.
- **A strings row nothing in the run reads as its kind is exported as its form.** A name, device path or volume
  path that only its written form makes look like a host is exported under that form on every feed, never as a
  domain; its context says no reading of it as a host, and the console shows it standing alone. A strings row the
  run publishes, another source holds or the judge names keeps its kind.
- **A sentence that already states why a value is not published is not marked again.** The check reads a restated
  reason from the clause right after the value to the end of its clause group, whatever commas the reason holds; a
  reason that begins in a later clause states no publish state.
