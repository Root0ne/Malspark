### Fixed

- **A technique's description in `mitre.json` is the text the analyst report's ATT&CK table prints for it (T-727).** It is read off the render that prints the table, so a sentence the agreement question or the flagged-statement gate leaves out is not described, a written procedure that replaces the claim is, and the description is whole: no claims joined, no cut at 512 characters; a row that prints `-` is described `""`. `/reports/{id}/mitre` and the console's download derive it from the served report at each request, so a value an enrichment publishes after the build reads as the served table reads it, and the enrichment write stores the column again under its amendment. A stored report that does not validate serves its column as stored; the report detail, the run export and the job package copy the stored column, and the column the STIX fallback writes keeps the judge's own description.
